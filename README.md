# 📊 TDCC 集保股權分散統計工具 (TDCC-HoldingRatio)

[![GitHub License](https://img.shields.io/github/license/Yuno-Liu/TDCC-HoldingRatio)](LICENSE)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.7+-3178C6?logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![Manifest V3](https://img.shields.io/badge/Chrome%20Extension-Manifest%20V3-4285F4?logo=googlechrome&logoColor=white)](https://developer.chrome.com/docs/extensions/mv3/intro/)
[![CI](https://github.com/Yuno-Liu/TDCC-HoldingRatio/actions/workflows/ci.yml/badge.svg)](https://github.com/Yuno-Liu/TDCC-HoldingRatio/actions/workflows/ci.yml)

一個為台股投資人設計的 Chrome 擴充功能（Manifest V3 + TypeScript），專用於 [臺灣集中保管結算所 (TDCC) 集保戶股權分散表](https://www.tdcc.com.tw/portal/zh/smWeb/qryStock) 查詢頁面。
查詢個股後，自動解析 15 個持股級距，以**股數精算**大戶、中實戶、散戶的持股比例、人數與張數。

---

## ✨ 核心功能

- 🎯 **大戶／中實戶／散戶三族群統計**
  - 依「族群股數 ÷ 合計股數」精算比例，三族群互不重疊，人數加總等於總股東人數。
  - 每個族群顯示：持股比例、人數（含占總股東比例）、合計張數（滑鼠移上可看平均每人張數）。
  - 三色分布條一眼看出籌碼集中程度。
- ⚙️ **門檻自由設定，語意明確**
  - 大戶門檻以級距「下限」標示，例如 `> 400 張 · 400張大戶`、`> 1,000 張 · 千張大戶`。
  - 散戶門檻以級距「上限」標示，例如 `≤ 10 張`、`≤ 50 張`、`≤ 100 張`。
  - 所有選項皆可選；若與另一個門檻重疊，會保留剛選的門檻，另一個暫時讓位並顯示提示，衝突解除後自動還原成原本的選擇（例如用方向鍵瀏覽大戶選項時，散戶門檻不會被改掉）。
- 💾 **設定自動保存**：門檻、收合狀態、級距明細展開狀態與面板位置保存於 `chrome.storage.local`。TDCC 每次查詢都會整頁重新載入，設定不會被重設；多個分頁之間也會同步。
- 🔎 **級距明細**：展開即可看到 1～15 級的人數與 TDCC 公告比例（與頁面表格一致），以顏色標示各級距所屬族群，底部列出與上方卡片一致的族群合計，並說明兩者差異的原因。
- 📋 **一鍵複製結果**：複製證券代號、資料日期與三族群統計的文字摘要。
- 🖱️ **可拖曳、可收合**：拖曳標題列移動面板（位置會保存，並自動保持在可見範圍內）；收合後標題列顯示證券資訊與含門檻定義的摘要，例如「千張大戶 84.39% · ≤100張散戶 10.29%」。
- ♿ **無障礙**：鍵盤可完整操作（焦點在面板內時按 `Esc` 收合）、螢幕閱讀器標籤、WCAG AA 對比、支援「減少動態效果」。
- 🧱 **不干擾 TDCC 網站**：面板位於 Shadow DOM，樣式完全隔離；預設位於主選單下方，層級低於 TDCC 自身的彈出視窗；列印頁面時自動隱藏；閒置時不消耗 CPU。

## 🧮 計算方式

### TDCC 持股分級

| 級距 | 持股股數 | 張數 |
| --- | --- | --- |
| 1 | 1–999 | < 1 張（零股） |
| 2 | 1,000–5,000 | 1–5 張 |
| 3 | 5,001–10,000 | 5–10 張 |
| 4 | 10,001–15,000 | 10–15 張 |
| 5 | 15,001–20,000 | 15–20 張 |
| 6 | 20,001–30,000 | 20–30 張 |
| 7 | 30,001–40,000 | 30–40 張 |
| 8 | 40,001–50,000 | 40–50 張 |
| 9 | 50,001–100,000 | 50–100 張 |
| 10 | 100,001–200,000 | 100–200 張 |
| 11 | 200,001–400,000 | 200–400 張 |
| 12 | 400,001–600,000 | 400–600 張 |
| 13 | 600,001–800,000 | 600–800 張 |
| 14 | 800,001–1,000,000 | 800–1,000 張 |
| 15 | 1,000,001 以上 | > 1,000 張 |

### 族群定義（預設值）

- **大戶**：級距 ≥ 大戶門檻。預設第 15 級（`> 1,000 張`，即「千張大戶」）；常用的「400 張大戶」為第 12～15 級。
- **散戶**：級距 ≤ 散戶門檻。預設第 1～9 級（`≤ 100 張`）。
- **中實戶**：介於兩門檻之間的級距（預設第 10～14 級）。

### 比例計算

```
族群持股比例 = 族群內各級距股數加總 ÷ 合計股數（第 17 列）× 100%
```

- 分母使用「合計」列股數，與 TDCC「占集保庫存數比例」欄位的分母相同。
- **為什麼不直接加總 TDCC 的比例欄位？** TDCC 比例欄位是以**無條件捨去**取到小數第 2 位（以 2026/10/30 全市場 4,111 檔、61,665 個欄位驗證，無一例外）。直接加總時，每個級距都會少算 0～0.01 個百分點，散戶（9 個級距）最多可能低估約 0.09 個百分點。以 2330 台積電 115/10/22 為例，散戶（≤ 100 張）加總比例欄為 10.20%，以股數精算為 **10.24%**。
- 「差異數調整」（第 16 列）是因資料日前一營業日賣出餘額不足等因素，造成各級距合計股數與已發行股數之間的差異。少數證券（多為 ETF）的差異較明顯，此時三族群比例加總會略高於 100%，面板會主動顯示說明。
- 級距明細中的各級比例保留 TDCC 公告值（方便與頁面表格對照），因此逐級加總會略低於族群合計（每個級距最多少 0.01 個百分點），這是 TDCC 無條件捨去造成的，族群合計才是精確值。
- 少數證券沒有「差異數調整」列，此時「合計」位於第 16 列，解析時以文字辨識，不受影響。
- 若頁面的股數欄位不完整，會自動退回加總比例欄位，並在底部狀態列標示「依比例欄加總」。

### v1.1.0 修正的計算問題

1. **大戶門檻差一個級距**：舊版大戶與散戶下拉選單共用「級距上限」文字，但大戶的判斷是「≥ 該級距」。例如選「400」實際是從第 11 級（200,001 股起）開始計算，等於「> 200 張」，多算了整個第 11 級（200～400 張）；以 2330 為例多算 1.44 個百分點、1,330 人。新版大戶選單改以級距下限標示，「400 張大戶」對應第 12～15 級。
2. **比例欄位無條件捨去造成系統性低估**：見上方說明，新版改用股數精算。
3. **門檻可重疊導致重複計算**：舊版可讓散戶門檻 ≥ 大戶門檻，兩者相加超過 100%。新版保證兩族群不重疊，衝突時自動調整另一個門檻。

## 🚀 安裝說明

### 方式一：從 GitHub Releases 下載（推薦，開箱即用）

無需安裝 Node.js 或自行編譯，直接下載最新發布檔：

1. 前往本專案的 [Releases 頁面](https://github.com/Yuno-Liu/TDCC-HoldingRatio/releases)。
2. 下載最新發布的 `TDCC-HoldingRatio-v*.zip` 檔案。
3. 解壓縮至電腦任意資料夾。
4. 開啟 Chrome 瀏覽器，在網址列輸入 `chrome://extensions/` 並按 Enter。
5. 開啟右上角 **「開發人員模式」 (Developer mode)**。
6. 點選左上角 **「載入未封裝項目」 (Load unpacked)**。
7. 選取解壓縮後的 `dist` 目錄即可完成安裝！
8. 造訪 [TDCC 集保戶股權分散表查詢頁面](https://www.tdcc.com.tw/portal/zh/smWeb/qryStock) 即可自動啟用。

### 方式二：從原始碼自行編譯（開發者用）

需要 Node.js 22.22+ 或 24.15+。

1. 克隆專案並安裝相依套件：
   ```bash
   git clone https://github.com/Yuno-Liu/TDCC-HoldingRatio.git
   cd TDCC-HoldingRatio
   npm install
   npm run build
   ```
2. 開啟 Chrome `chrome://extensions/`，啟用「開發人員模式」，點選「載入未封裝項目」，選擇 `dist` 目錄完成安裝。

### 權限說明

- `storage`：保存門檻、收合狀態與面板位置（僅存於本機）。
- 僅在 `https://www.tdcc.com.tw/portal/zh/smWeb/qryStock*` 頁面執行，不會讀取其他網站，也不會傳送任何資料。

## 📖 使用方式

1. 進入臺灣集中保管結算所的「集保戶股權分散表」查詢頁面。
2. 輸入證券代號（例如：`2330`）並按「查詢」。
3. 頁面右上角（主選單下方）的「**持股比例統計**」面板會自動顯示該證券的大戶、中實戶、散戶統計，標題列會顯示證券代號、名稱與資料日期。
4. 於面板上方的下拉選單調整「大戶門檻」與「散戶門檻」，結果即時更新並自動保存。
5. 其他操作：
   - 點擊標題列或右上角按鈕收合／展開；焦點在面板內時按 `Esc` 也可收合。
   - 拖曳標題列移動面板。
   - 展開「級距明細」檢視每個級距的人數與比例。
   - 「複製結果」將統計摘要複製到剪貼簿；「重新計算」強制重新解析頁面。

## 🛠️ 開發與測試

```bash
# 安裝相依套件
npm install

# 執行全部測試 (型別編譯 + 打包 + 單元／整合／打包產物測試)
npm test

# 編譯生產版本（產出 dist/）
npm run build

# 開發監聽模式（程式碼變更時即時打包）
npm run watch

# 執行 TypeScript 靜態型別檢查
npm run typecheck

# 清除構建產物
npm run clean
```

### 測試涵蓋範圍

- **解析器**：以實際擷取的 TDCC 回應頁面（有資料、查無資料、尚未查詢）驗證，含差異數調整負數、全形空白「合　計」、隱含 `<tbody>` 等真實格式。
- **計算**：以 TDCC 開放資料（分層抽樣 67 檔，含 ETF 與差異數調整明顯者）驗證全部 105 種門檻組合，與獨立參考實作比對；並驗證 TDCC 比例欄為無條件捨去。
  - 可用完整開放資料驗證全市場：下載 [股權分散表 CSV](https://opendata.tdcc.com.tw/getOD.ashx?id=1-5) 後執行
    `TDCC_OPENDATA_CSV=/path/to/file.csv node --test tests/opendata.test.mjs`（需先 `npm run build:test`）。
- **面板互動**（jsdom）：門檻互斥、設定保存與跨分頁同步、收合／Esc、拖曳、複製、閒置不重繪、表格替換自動更新、重新注入。
- **發佈產物**：直接執行打包後的 `dist/content.js` 並檢查 `manifest.json`。
